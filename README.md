# Student-Registration-Result-Portal
# Student Registration & Result Portal

## Technologies
- HTML5
- Bootstrap 5
- JavaScript
- CSS3

## How to run
1. Extract the project folder.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Enter student details.
4. Enter marks from 0 to 100.
5. Click **Calculate Result**.

## Pass Rule
A student passes only when they score at least 40 marks in every subject.

## Files
- `index.html` - webpage structure and Bootstrap components
- `style.css` - custom styling
- `script.js` - validation, calculation, DOM manipulation and dynamic result
